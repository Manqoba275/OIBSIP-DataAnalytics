# Data source notes

The file in this folder is the 1,000-row Retail Sales Dataset by Mohammad Talib on Kaggle. Kaggle lists the dataset as CC0: Public Domain. The dataset publisher describes it as synthetic/constructed sample data, not verified business records. Its currency is not specified.

The original transaction columns are kept unchanged: Transaction ID, Date, Customer ID, Gender, Age, Product Category, Quantity, Price per Unit and Total Amount. Product names/SKUs and repeat-purchase history are not included, so this analysis does not invent either.
