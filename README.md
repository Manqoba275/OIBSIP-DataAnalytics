# OIBSIP - Data Analytics

Projects prepared for the OASIS INFOBYTE Data Analytics track.

## Current project

`DataAnalytics-L1-EDARetailSales/` contains the Level 1, Task 1 exploratory analysis of retail sales data. Open its `notebooks/EDA_Retail_Sales.ipynb` in VS Code, or use its `scripts/run_analysis.py` to rebuild the figures and findings report. Project setup and dataset caveats are in that folder's README.

## Submission note

The supplied task guide says the full Data Analytics track requires at least three Level 1 or Level 2 tasks. This repository currently contains one task, so the other required tasks remain. The guide also asks for one public repository named exactly `OIBSIP`; this separate `OIBSIP-DataAnalytics` repository follows the owner's earlier choice to keep Java and Data Analytics in separate repositories. Check the coordinator's submission rule before submitting if the repository name is enforced strictly.
